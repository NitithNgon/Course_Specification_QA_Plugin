# Course Specification

## 1. Course Information
- **Course Code:** CPE599
- **Course Name:** Computer Graphics

## 2. Learning Outcomes

| CLO | Description | Bloom Level | PLO |
|---|---|---|---|
| CLO1 | Describe the mathematical foundations of 2D/3D transformations used in rendering pipelines | Understand | PLO1 |
| CLO2 | Implement a rasterization-based rendering pipeline for basic 3D scenes | Apply | PLO3 |
| CLO3 | Compare rendering techniques (rasterization vs. ray tracing) for a given application's performance and quality requirements | Analyze | PLO2 |
