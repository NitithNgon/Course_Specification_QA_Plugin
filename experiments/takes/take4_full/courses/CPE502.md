# Course Specification

## 1. Course Information
- **Course Code:** CPE502
- **Course Name:** Computer Graphics

## 2. Learning Outcomes

| CLO | Description | Bloom Level | PLO |
|---|---|---|---|
| CLO1 | Explain the real-time rendering pipeline and its major stages | Understand | PLO1 |
| CLO2 | Implement a shader-based lighting model for a 3D scene | Apply | PLO3 |
| CLO3 | Design an original game level applying the design principles covered in class | Create | PLO3 |

## 4. Course Policies
- **Attendance:** Studio attendance is required for project critique sessions; two missed critiques forfeit the project's participation credit.
- **Deadlines:** Milestone deliverables follow a fixed schedule; late submissions lose 10% per day.
- **Academic Integrity:** Shader code and level-design assets submitted must be the student's own work.
- **Plagiarism and False Citation:** Reusing another student's shader code or an uncredited asset pack without permission/attribution is a violation.
- **AI Tools & Critical Use:** AI-generated art or code assets must be disclosed; core lighting-model logic being assessed must be student-authored.
