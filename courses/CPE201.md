# Course Specification

## 1. Course Information
- **Course Code:** CPE201
- **Course Name:** Data Structures and Algorithms

## 2. Learning Outcomes

| CLO | Description | Bloom Level | PLO |
|---|---|---|---|
| CLO1 | Explain the time and space complexity of common data structures | Understand | PLO1 |
| CLO2 | Apply appropriate data structures to solve a given programming problem | Apply | PLO3 |
| CLO3 | Analyze the trade-offs between competing algorithm designs for a problem | Analyze | PLO2 |

## 4. Course Policies
- **Attendance:** Students must attend at least 80% of sessions to be eligible for the final exam.
- **Deadlines:** Assignments submitted late lose 10% of the score per day, up to 3 days; not accepted after.
- **Academic Integrity:** All submitted work must be the student's own; violations are handled under the faculty's academic integrity policy.
- **Plagiarism and False Citation:** Any uncredited use of another's code or text, or fabricated citations, results in a zero for the assignment and a report to the department.
- **AI Tools & Critical Use:** Students may use AI coding assistants for boilerplate only; AI-generated logic must be understood and explainable on request, and must be disclosed in the submission header.
