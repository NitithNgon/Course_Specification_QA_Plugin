# Course Specification

## 1. Course Information
- **Course Code:** CPE501
- **Course Name:** Machine Learning Fundamentals

## 2. Learning Outcomes

| CLO | Description | Bloom Level | PLO |
|---|---|---|---|
| CLO1 | Explain the bias-variance trade-off and common regularization techniques | Understand | PLO1 |
| CLO2 | Define the standard supervised learning model families (linear, tree-based, neural) | Create | PLO3 |
| CLO3 | Apply cross-validation to select hyperparameters for a given dataset | Apply | PLO3 |

## 4. Course Policies
- **Attendance:** Students must attend at least 80% of sessions to be eligible for the final exam.
- **Deadlines:** Assignments submitted late lose 10% of the score per day, up to 3 days; not accepted after.
- **Academic Integrity:** All submitted work must be the student's own.
- **Plagiarism and False Citation:** Uncredited use of another's code, text, or fabricated citations results in a zero and a department report.
- **AI Tools & Critical Use:** Students may use AI coding assistants for boilerplate only; AI-generated logic must be disclosed and explainable on request.
