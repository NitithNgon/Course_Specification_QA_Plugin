# Course Specification

## 1. Course Information
- **Course Code:** CPE305
- **Course Name:** Database Systems

## 2. Learning Outcomes

| CLO | Description | Bloom Level | PLO |
|---|---|---|---|
| CLO1 | Describe the relational model and normalization theory | Understand | PLO1 |
| CLO2 | Design a normalized relational schema for a given business scenario | Create | PLO3 |
| CLO3 | Evaluate query plans and justify indexing choices for performance | Evaluate | PLO4 |

**Total: 100**

### Scoring Criteria Checklist
- [x] Rubric published on the LMS before the due date
- [x] Grading criteria weighted per learning outcome
- [x] Peer review checklist provided for the project's schema design deliverable

## 4. Course Policies
- **Attendance:** Attendance is recorded each session; more than 4 unexcused absences bars the student from the final exam.
- **Deadlines:** Project milestones are fixed dates; a 1-day grace period is allowed once per student per semester.
- **Academic Integrity:** Database schemas and queries submitted must be individually authored unless explicitly marked as a group deliverable.
- **Plagiarism and False Citation:** Copying schema designs or query logic from another student or an uncredited source is an academic integrity violation.
- **AI Tools & Critical Use:** AI tools may be used to explore query alternatives, but the final schema design rationale must be written and defended by the student in their own words during the project review.
