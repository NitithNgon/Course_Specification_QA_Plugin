14. Course plan

    General and/or behavioural objectives

    1. Explain the stages of the machine-learning system lifecycle
    2. Manage data and data systems for machine-learning systems
    3. Design, develop and evaluate machine-learning systems
    4. Apply machine-learning operations practices

    Detailed content: understanding ML systems; designing an ML system; ML-systems fundamentals; data-systems fundamentals; data management; model development; model evaluation; model deployment; system monitoring; ML infrastructure and platforms; ML operations.

    Teaching methods: lectures with weekly tutorials.
    Teaching media: slides; supplementary lecture videos.

17. Term project requirements

    Groups of four or five students design, implement and demonstrate a working software system with at least one machine-learning use case. The project documents its architecture with the C4 model (context, container, component and code diagrams for the ML component), and the live demonstration shows data management and versioning, reproducible experiments with more than one model run, model evaluation, a working deployment with basic automation, monitoring of model performance, and the team's development process. Each group has 30 minutes: 20 minutes for the presentation and live demonstration and 10 minutes for questions.
