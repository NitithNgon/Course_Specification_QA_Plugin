### Course description (คำบรรยายรายวิชา)

Operating-system structure; processes and threads; CPU scheduling; synchronization and deadlocks; memory management and virtual memory; file systems; input and output.

## Program learning outcomes related to the course (ผลลัพธ์การเรียนรู้ระดับหลักสูตรที่เกี่ยวข้องกับรายวิชา)

- PLO1: Engineering knowledge
- PLO2: Problem analysis
- PLO3: Design/development of solutions

### Assessment note (หมายเหตุเกี่ยวกับการประเมินผลการเรียน)

- Bonus: students who complete the online course "Operating Systems Fundamentals" and submit its certificate receive up to 5 bonus points on top of the 100 above.
- Late work: assignments submitted after the deadline lose 20% of their mark and are accepted up to 2 days late.
- Academic integrity: kernel and concurrency code must be your own implementation, built from the provided skeleton. Reusing another student's code or an uncredited open-source implementation is a violation.
- AI tools: AI-assisted debugging is allowed for compiler errors only; AI must not write the synchronization logic being assessed.
- Attendance: attendance is not graded, and there is no attendance penalty.
