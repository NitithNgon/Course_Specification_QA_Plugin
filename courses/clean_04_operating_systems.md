# Course Specification

## 1. Course Information
- **Course Code:** CPE410
- **Course Name:** Operating Systems

## 2. Learning Outcomes

| CLO | Description | Bloom Level | PLO |
|---|---|---|---|
| CLO1 | Explain process scheduling, memory management, and synchronization mechanisms | Understand | PLO1 |
| CLO2 | Implement a multithreaded solution to a producer-consumer problem using semaphores | Apply | PLO5 |
| CLO3 | Critique the trade-offs of two scheduling algorithms for a given workload and recommend one | Evaluate | PLO2 |

## 3. Assessment

| Component | Weight (%) | CLO Mapped |
|---|---|---|
| Midterm Exam | 25 | CLO1 |
| Final Exam | 25 | CLO1, CLO3 |
| Assignment | 30 | CLO2 |
| Project | 20 | CLO2, CLO3 |

**Total: 100**

### Scoring Criteria Checklist
- [x] Rubric published on the LMS before the due date
- [x] Concurrency assignments graded with an automated race-condition test suite plus manual code review

## 4. Course Policies
- **Attendance:** Attendance is not directly graded but is strongly correlated with lab performance; no formal penalty.
- **Deadlines:** Assignments submitted after the deadline receive a flat 20% deduction, accepted up to 2 days late.
- **Academic Integrity:** Kernel-level and concurrency code submitted must be the student's own implementation, built from the provided skeleton only.
- **Plagiarism and False Citation:** Reusing another student's synchronization logic or an uncredited open-source implementation is a violation.
- **AI Tools & Critical Use:** AI-assisted debugging is permitted for compiler errors only; AI must not be used to generate the core synchronization logic being assessed.
