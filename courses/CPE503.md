# Course Specification

## 1. Course Information
- **Course Code:** CPE503
- **Course Name:** Game Programming

## 2. Learning Outcomes

| CLO | Description | Bloom Level | PLO |
|---|---|---|---|
| CLO1 | Give students a foundation in game design, both individually and in teams | Understand | - |
| CLO2 | Develop skills to analyze and critique the design of games made by others and by oneself | Analyze | PLO2 |
| CLO3 | Build a working computer game as part of a team | Create | PLO3 |

## 3. Assessment

| Component | Weight (%) | CLO Mapped |
|---|---|---|
| Attendance | 1 | CLO1 |
| Group Work | 29.5 | CLO1, CLO3 |
| Individual | 29.5 | CLO1, CLO2 |
| Term Project | 40 | CLO1, CLO3 |

**Total: 100**

### Scoring Criteria Checklist
- [x] Rubric published on the LMS before the due date
- [x] Grading criteria weighted per learning outcome

## 4. Course Policies
- **Attendance:** Attendance is graded directly per the weight above.
- **Deadlines:** Term project milestones follow a fixed schedule; late milestones lose 10% per day.
- **Academic Integrity:** Individual work must be the student's own; team work must reflect the whole team's contribution.
- **Plagiarism and False Citation:** Reusing another team's game assets or design document without attribution is a violation.
- **AI Tools & Critical Use:** AI-assisted asset generation must be disclosed in the project's credits page.
